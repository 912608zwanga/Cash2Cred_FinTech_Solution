# Cash2Cred FinTech Solution

Cash2Cred is a Vite and React fintech application for informal trade, stock, cash-to-credit, receipts, reviews, subscriptions, and credit-passport workflows.

## Live application

👉 [Open the deployed app](https://cash2cred-fintech-solution.vercel.app)

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deployment

The application is deployed with Vercel and connected to this GitHub repository. Changes pushed to the `main` branch trigger a deployment.
